Hôm nay: Testing Spring Boot.
Phần 1: test càng thật càng chậm nhưng càng đáng tin: nhiều test nhanh ở đáy, ít test nặng ở đỉnh.
Đo từng class: unit ~1 s, @WebMvcTest 0,8 s, @DataJpaTest + H2 2,1 s.
PostgreSQL container 19 s, Redis 23 s, Kafka 72 s: chênh lệch hàng chục lần.
Toàn @SpringBootTest: suite chậm. Mock hết: query sai lọt. Test behavior, không test implementation.
Phần 2: MockitoExtension, @Mock repository, @InjectMocks service. Không cần khởi động Spring.
Mock giả hoàn toàn: add() rồi size() = 0. Spy bọc object thật: size() = 1.
Bẫy của spy: when(spy.get(5)) gọi method thật trước, nên ném lỗi. Dùng doReturn.
Mock chưa stub trả rỗng. Strict stubs báo lỗi khi stub thừa.
Mock ở ranh giới. Đừng mock DTO, đừng any() khắp nơi.
Phần 3: @WebMvcTest chỉ dựng tầng web. Không có service, repository.
Không user: 401. Có user, service ném NotFound: 404 problem+json.
POST không CSRF: 403. Có CSRF, body sai: 400. Body đúng: 201 kèm Location.
Bẫy: SecurityConfig của bạn không được nạp: @Import nó và gửi .with(jwt()).
Dùng @MockitoBean thay @MockBean (deprecated). Mỗi tổ hợp khác nhau là một context mới.
Phần 4: @DataJpaTest chỉ load JPA, thay DataSource bằng H2, mỗi test chạy trong transaction rồi rollback.
Native query ON CONFLICT: H2 lỗi cú pháp; PostgreSQL 16 thật: lần 1 trả 1, lần 2 trả 0.
H2 khác ở jsonb, collation, SKIP LOCKED, migration: test repository trên Testcontainers cùng version production.
Nhớ flush và clear. Quên flush thì lỗi constraint không bao giờ nổ.
Code @Async ở thread khác không rollback. Sang container quên ddl-auto: thiếu bảng.
Phần 5: @SpringBootTest + Testcontainers chạy PostgreSQL, Redis, Kafka thật trong Docker.
Từ Boot 3.1, @ServiceConnection tự tạo thông tin kết nối. Đã chạy cả 3 loại container.
Container phải static. Ghim version image, đừng dùng latest.
@SpringBootTest không tự rollback; RANDOM_PORT phải tự dọn. @DirtiesContext phá context cache.
Phần 6: test flaky lúc pass lúc fail dù code không đổi. Nguy hiểm vì cả nhóm quen "chạy lại cho xanh".
Thời gian: LocalDate.now() lúc nửa đêm → inject Clock cố định.
Bất đồng bộ: sleep rồi assert → dùng Awaitility chờ tới khi điều kiện đúng.
Thứ tự: mỗi test tự chuẩn bị và dọn dữ liệu; đừng assert thứ tự không đảm bảo.
