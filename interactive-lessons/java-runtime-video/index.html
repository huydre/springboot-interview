Chặng 3 · StampedLock
Đọc lạc quan
ReadWriteLockMỗi lần đọcđều lấy và nhả khoá
StampedLockĐọc không khoárồi kiểm tra có ai ghi chen vào
Hợp khi đọc rất nhiều, ghi rất ít, đoạn đọc ngắn
Optimistic.java
long stamp = lock.tryOptimisticRead();
int v = data[0];
if (!lock.validate(stamp)) {
    stamp = lock.readLock();
    try { v = data[0]; }
    finally { lock.unlockRead(stamp); }
}
1. đọc không khoá
2. validate: có ai ghi chen vào?
3. có thì đọc lại bằng readLock
Đã chạy: sau một lần ghi, validate trả false
Đã chạy: writeLock lần hai trong cùng thread bị từ chối
