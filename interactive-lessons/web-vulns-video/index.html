SQL injection
Dữ liệu thành câu lệnh
Nối chuỗi đầu vào cho phép người dùng sửa câu lệnhCách chặn bền vững: câu lệnh tham số hoá (prepared statement)
input = ' OR '1'='1
Nối chuỗi
String sql = "SELECT * FROM users WHERE name = '" + input + "'";
SELECT * FROM users WHERE name = '' OR '1'='1'
✕ Điều kiện luôn đúng: trả về mọi người dùng
Prepared statement
PreparedStatement ps = conn.prepareStatement("SELECT * FROM users WHERE name = ?");
ps.setString(1, input);        // giá trị truyền riêng, luôn là dữ liệu
✓ ' OR '1'='1 chỉ là một chuỗi cần so khớp
Spring Data JPA: @Query("... where u.name = :name") + @Param, hoặc findByName
Tên cột, tên bảng, hướng ORDER BY không bind được: so khớp allowlist
Câu SQL cố định, giá trị truyền riêng
đừng tự escape dấu nháy thay cho tham số hoá
